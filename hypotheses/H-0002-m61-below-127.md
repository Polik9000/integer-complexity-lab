# H-0002: ‖2^61 − 1‖ < 127

- **Status:** REFUTED (provisional: one implementation; EXP-0002 shows ‖2^61−1‖ = 127)
- **Related:** RQ-1, RQ-4; R-0003, R-0005
- **Statement:** Some expression for 2^61 − 1 uses at most 126 ones.
- **Evidence so far:** None either way. A narrow peel search plateaus at 127 (OBSERVATION, EXP-0001).
  The generic lower bound is 116. He (2024, Table 1) estimates the average of ‖n‖/log₃ n near
  n = 10¹⁸ at ≈ 3.3296 by sampling. For N that gives 3.3296 · log₃ N ≈ 128.1, so 127 is already
  slightly *better than typical*. The highly composite N − 1 plausibly helps. This is a heuristic,
  not evidence about ‖N‖.
- **What would settle it:** a ≤ 126-ones certificate (confirms), or an exact computation giving 127 (refutes).
- **History:** 2026-11-25 created. 2026-11-25 refuted (provisionally) by EXP-0002. Final once EXP-0003 replicates it.
