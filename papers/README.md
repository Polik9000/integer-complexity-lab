# papers/

Drafts intended for eventual publication (preprints, notes, a table of ‖2^k − 1‖).
Nothing here is submitted or posted without the human lead's explicit approval.
Use LaTeX (`papers/<slug>/main.tex`) or Markdown. Shared BibTeX goes in `papers/references.bib`,
kept consistent with BIBLIOGRAPHY.md (see the `citation-management` skill).
